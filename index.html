GitHub Copilot at VA
How to Get Access & Get Started

A complete guide for VA employees who want to use GitHub Copilot in their daily development workflow.

1 Join VA GitHub 2 Request Access 3 Install in IDE 4 Teams Channels 5 VA Resources 6 GHEC‑US Links 7 Training 8 Troubleshooting 9 Quick Checklist

GitHub Copilot is an AI coding assistant that helps you write, understand, and improve code directly inside your preferred IDE (VS Code, Visual Studio, JetBrains, NeoVim, etc.). At the VA, Copilot is available only through the VA's GitHub Enterprise Cloud (GHEC‑US) environment at va.ghe.com.

This guide provides everything a new VA user needs to join the VA GitHub organization, request Copilot access, set up their editor, connect with the community, and find training and support.

Step 1

Prerequisite: Join the VA GitHub Organization

VA Copilot licenses are available only to users who are part of the official VA GitHub org. Submit the signup form below (requires VA network access). Once approved, your GHEC‑US account will be created using VA Single Sign‑On (Entra ID).

Step 2

Request GitHub Copilot Access

Once you are in the VA GitHub organization, request Copilot access using the form below. Access is typically granted automatically within minutes.

Request Copilot Access →
Step 3

Install GitHub Copilot in Your IDE

After you receive your "Welcome to Copilot Enterprise!" email, install Copilot in your preferred editor using the official setup guides:

VS Code Visual Studio JetBrains NeoVim
⚠ Important: When signing in to VS Code or any editor, use your VA GitHub Enterprise account (va.ghe.com), not GitHub.com.
If you see a "Free plan" warning, you are signed in with the wrong GitHub account.

Step 8

Troubleshooting Tips

VS Code shows "Free Plan"

You are logged in with a GitHub.com account, not your VA enterprise account.

Fix: Log out and log back in using va.ghe.com.

Firewall or Reachability Errors

Post the error in the GHEC‑US‑Users Teams channel. You may be asked to open a GitHub Admin support request.

Copilot Access Suddenly Disappeared

1. Submit a new Copilot Access Request.

2. Verify you are still a member of the VA GitHub organization.
